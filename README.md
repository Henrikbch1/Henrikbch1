### 🤖 So arbeite ich mit KI

```text
Anforderung  →  Spezifikation & Plan  →  Umsetzung mit Coding Agent  →  Review & Tests  →  CI  →  Deployment
```

- **Kontext statt Zufall:** Projektspezifische Agent-Anweisungen (`copilot-instructions.md`, Custom Agents, Agent Skills) halten Architektur- und Stilregeln fest.
- **Kleine, prüfbare Schritte:** Feature-Branches, Pull Requests und Conventional Commits – jede Änderung wird gelesen, bevor sie gemerged wird.
- **Absicherung:** Linting, Unit-Tests und CI-Pipelines prüfen, was der Agent erzeugt.
- **Tools:** Claude Code · GitHub Copilot · OpenAI Codex · Agent Skills
